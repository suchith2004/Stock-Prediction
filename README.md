 📈 Stock Price Prediction using LSTM and ANN

 📌 About Project
This project predicts future stock prices using machine learning and deep learning.

We use past stock data to understand patterns and predict future trends.

 🤖 Models Used
- LSTM (Long Short-Term Memory)
- ANN (Artificial Neural Network)

 🎯 Goal
To compare LSTM and ANN and find which model gives better stock price prediction.

 🛠️ Tools Used
- Python
- Pandas
- NumPy
- TensorFlow / Keras
